    export const jsonColumnConfig = {
      prepare: (value: any) => (value != null ? JSON.stringify(value) : null),

above IS the convention.

Sharing one config object across many decorators is SAFE
(`node_modules/@adonisjs/lucid/build/src/orm/base_model/index.js:210`): `$addColumn` copies
every field into a brand-new object and derives `columnName` / `serializeAs` per property. It
