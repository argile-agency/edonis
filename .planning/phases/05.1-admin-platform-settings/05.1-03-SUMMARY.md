# Phase 05.1 Plan 03: Public settings rendering Summary

The home page, header and Edge layout now render the admin settings: a plain-text announcement banner whose contact email becomes a mailto link, a hero image, a footer contact group (email, « Aide et support », social icons), a hidden sign-up CTA and header link when registration is closed, an admin-only « Réglages de la plateforme » dropdown entry, and a favicon `<link>`. Every admin-set URL passes the `safe_url` render guards, so it renders only if it is http(s) or a safe root-relative path.

## Deviations from Plan

None. A few small implementation choices are worth knowing:
- The favicon partial uses `page.props.appSettings && page.props.appSettings.appFaviconUrl` instead of `?.`, to stay safe with Edge's expression parser. The null-settings test covers it.
- The `safe_url.ts` regex has an `eslint-disable-next-line no-control-regex` because it rejects control characters on purpose.
