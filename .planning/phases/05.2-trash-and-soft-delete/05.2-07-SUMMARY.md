# Phase 05.2 Plan 07: Read-path visibility, gradebook filter and check:debt gate Summary

The gradebook now hides the assignments of a trashed section. It writes nothing to assignments, so restoring the section brings them back. The reorder endpoints no longer overwrite a trashed row's order. An 18-test HTTP spec walks every read path of the inventory with trashed rows present. `check:debt` fails on any new raw read of the structure tables that has no marker.

## Known blind spots of the check:debt grep

The visibility spec remains the real guard. The grep does not catch:
- `whereHas` / `has`
- `rawQuery` / `knex.raw`
- `innerJoin` / `rightJoin` / `crossJoin`
- `.table('course_…')`
- a table name passed through a variable
- new `Assignment.query()` calls that skip `hideTrashedSections`
