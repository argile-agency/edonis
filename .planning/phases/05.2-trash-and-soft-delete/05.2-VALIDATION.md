## Sampling Rate

- **After every task commit:** the touched spec file(s) on SQLite + `bun run typecheck` + `bun run check:debt` (each task's `<automated>` verify)
- **After every plan wave:** `node ace test unit functional` + `bun run lint` + `bun run check:debt`
- **Before `/gsd:verify-work`:** full suite green, `bun run build`, seeded migration check (05.2-10)
- **Max feedback latency:** ~90 s per task verify (touched spec files only, app boot included); the full unit + functional suite (~3-4 min) runs once per plan before its SUMMARY and per wave merge
