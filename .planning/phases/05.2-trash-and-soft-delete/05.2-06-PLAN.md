<!-- TRASH SERVICE RESTORE/LIST CONTRACT — identical copy in 05.2-06 (producer) and 05.2-09 (consumer). -->
- `type RestoreTarget = { kind: 'section' | 'content'; id: number }`
- `type RestoreOptions = { withSection?: boolean; moduleId?: number }`
- `type RestoreResult = { outcome: Outcome; title: string; batch: string; sectionIds: number[]; contentIds: number[]; restoredSection: { id: number; title: string } | null; destination: { id: number; title: string } | null; fallback: boolean }` — `outcome.affected` = restored ids; `touchedParents`/`touchedSections` = sibling lists renumbered (for `withRenumbered`); `restoredSection` set when `withSection` restored the content's section; `destination` set for `moduleId`; `fallback` true when a section went to the root end instead of its original place.
- `static async restore(trx, courseId: number, target: RestoreTarget, options?: RestoreOptions): Promise<RestoreResult>` — throws `BulkRefusal(404, { code: 'E_NOT_IN_TRASH', message: "Cet élément n'est plus dans la corbeille." })`, `BulkRefusal(409, { code: 'E_PARENT_TRASHED', section: { id, title }, message: 'La section de ce contenu est dans la corbeille. Restaurez-la ou choisissez une autre section.' })`, `BulkRefusal(422, { code: 'E_DEPTH' | 'E_INVALID_DESTINATION', message })` (explicit `moduleId` refused). Caller holds the course lock.
- `static async restoreBatch(trx, courseId: number, batch: string): Promise<RestoreResult>` — every root of the batch (`title` = first root's title, `fallback` true if any section fell back); same errors; all-or-nothing.
- `type TrashListRow = { kind: 'section' | 'content'; id: number; title: string; type: string | null; originalSection: { id: number; title: string } | null; sectionTrashed: { id: number; title: string } | null; deletedBy: string | null; deletedAt: string; daysLeft: number; batch: string; descendantCount: number; contentIds: number[] }` — `type` is the content type (`page | file | video | link | assignment | quiz`) or null for a section; `originalSection` = parent section (null = course root); `sectionTrashed` = that parent when it is itself trashed (content rows only); `deletedBy` = the user's `full_name`; « Utilisateur sans nom » when the user exists with a null/empty `full_name`; null only when the user row is missing (rendered « Utilisateur supprimé »); `deletedAt` ISO 8601; `daysLeft = Math.ceil((deletedAt + retentionDays days − now) / 1 day)`; `descendantCount` = trashed rows under a section row (any batch); `contentIds` = the content itself, or every trashed content under the section (any batch: the permanent-delete learner count).
- `static async list(courseId: number, retentionDays: number, client: QueryClientContract, now = DateTime.now()): Promise<TrashListRow[]>` (`client` required: `db` for the page, `trx` inside a transaction) — roots only, sorted `deletedAt desc, id desc`. Shortcut comment: no pagination; a course trash is small; paginate past about 200 roots.
