TrashService API created here (05.2-06 and 05.2-09 extend/consume it):
- `static async trash(trx: TransactionClientContract, courseId: number, roots: Ids, userId: number): Promise<{ batch: string; deleted: Ids }>` — subtree computed from `loadBuilderStructure(courseId, trx)` (live rows only) with the `childrenOf`/`contentsOf` walk of `course_bulk_actions_controller.ts:514-538`; raw `trx.from(table).whereIn('id', chunk).whereNull('deleted_at').update({ deleted_at, deleted_batch, deleted_by_id })` in `PIVOT_CHUNK` chunks; no `updated_at` bump, no sibling renumbering (stored `order` is what restore uses).
- `type TrashedRow = { kind: 'section' | 'content'; id: number; title: string; type: string | null; parentId: number | null; order: number; deletedAt: DateTime; batch: string; deletedById: number | null }` (`parentId` = `parent_id` for a section, `module_id` for a content).
- `static async trashedRows(client: QueryClientContract, courseId: number): Promise<TrashedRow[]>` (`client` required) — raw reads: `course_modules where course_id = ? and deleted_at is not null`; `course_contents join course_modules on module_id where course_modules.course_id = ? and course_contents.deleted_at is not null` (qualified columns).
- `static rootsOf(rows: TrashedRow[]): TrashedRow[]` — rows whose parent is not a trashed row of the same batch.
- `static async countRoots(courseId: number, client: QueryClientContract): Promise<number>` (`client` required: `db` outside a transaction, `trx` inside).
- `static toDbDateTime(dt: DateTime, client): string` = `dt.toFormat(client.dialect.dateTimeFormat)`; `static fromDbDateTime(value: Date | string): DateTime` (`Date` on pg/mysql2 → `DateTime.fromJSDate`, string on SQLite → `DateTime.fromSQL`, both in the app zone).
