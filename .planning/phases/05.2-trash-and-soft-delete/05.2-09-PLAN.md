## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05.2-36 | Elevation of privilege | delete/empty by collaborators | mitigate | `authorize('emptyTrash')` (owner; admins via `before`) server-side; 403 tests for edit and manage collaborators |
| T-05.2-37 | Elevation of privilege | view/restore by non-editors | mitigate | route `auth` + `role` middleware and `authorize('edit')`; 403 tests for teacher non-editor and student |
| T-05.2-38 | Tampering (IDOR) | ids/batch/moduleId of another course | mitigate | service scopes everything to `params.id`; 404/422 tests |
| T-05.2-39 | Tampering (input) | payloads | mitigate | VineJS validators (enum kind, positive ints, uuid batch); 422 test for a bad uuid |
| T-05.2-40 | Repudiation | restore, delete, empty, page purge | mitigate | one ids-only audit row per mutation inside the transaction; page purge audited with the user |
| T-05.2-41 | Spoofing (CSRF) | new POST routes | mitigate | shield CSRF unchanged; tests use `.withCsrfToken()` (gate) |
| T-05.2-42 | Denial of service | lazy purge failure on page open | mitigate | try/catch + `logger.error`; test with a throwing stub |
