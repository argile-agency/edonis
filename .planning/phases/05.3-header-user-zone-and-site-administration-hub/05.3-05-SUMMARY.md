These runs used Playwright 1.64.1 with chromium-headless-shell 1248, which I downloaded with the project's own `playwright install chromium`. The database was SQLite `tmp/test.sqlite3`, migrated and seeded under `NODE_ENV=test`, and the server ran on `PORT=3541`.

  - the theme `bg-primary`/`text-primary-foreground` pair (header « Tableau de bord » button)

  - Tabs triggers

  The same suite also fails on the base for login, register, profile, courses, builder (actions menu) and admin settings, with non-header causes. After the trigger fix, dashboard went from red to green. The must-have "axe reports no critical/serious violation" is therefore **not met yet**: it needs the theme-token fix listed in deferred-items §1.
- One-off, uncommitted axe pass scoped with `.include('header')` on the four new states:

## Deviations from Plan

1. **[Rule 1 - Bug] Account menu trigger failed axe `label-content-name-mismatch`** (118057e).
   - Found during: Task 2.
   - Issue: `aria-label="Menu du compte"` did not contain the visible initials. Every signed-in page failed, including the existing dashboard and builder cases.
   - Fix: replaced the aria-label with sr-only text and marked the trigger's Avatar `aria-hidden`. The accessible name is unchanged.
2. **[Rule 3 - Blocking] Login throttle in browser groups.**
   - The per-IP `loginThrottle` (5/min) lives in the test process's memory store, so a group with several logins gets 429 responses.
   - Added `group.each.setup(() => limiter.clear())` to the Header and Accessibility groups, following the precedent in `tests/functional/two_factor.spec.ts`.
3. **[Rule 3 - Blocking] Success toast over the header.**
   - « Connexion réussie » covers the user zone, and sonner pauses while hovered, so clicks timed out.
   - The login helpers reload after login.
4. **Search test data.** The search case creates its own course with a unique title through `createCourse(admin)` instead of using a seeded title, so it does not depend on seed content. The course is deleted in `finally`.
5. **Worktree setup (not committed).**
   - Fast-forwarded from b9888ef to the base 7607edd.
   - Copied `.env`, ran `bun install`, and ran `npm rebuild better-sqlite3` under Node 22.
   - Downloaded Chromium 1248 for the pinned Playwright.
   - Migrated and seeded `tmp/test.sqlite3`.
