# Phase 05.3 Plan 01: Edit mode server side Summary

Session flag `editMode = { userId }` toggled by `POST /edit-mode` (VineJS-validated, `CoursePolicy.edit` re-checked, redirects only to named course routes), exposed as the always-sent `editMode` shared prop and a `courseEditing` page prop on the three course pages, and forgotten on logout.

## Contract shipped (consumed by 05.3-04)

- Shared prop `editMode: boolean`, always sent; true only when the session flag's `userId` equals `auth.user.id` (malformed or foreign flags read as false; visitors false).
- Page prop `courseEditing: { courseId: number; canEdit: boolean }` on `courses/show` (reuses existing `canEdit`), `courses/learn` (`CoursePolicy.allows('edit')`), `courses/builder` (always true, `authorize('edit')` already passed). Absent elsewhere.
- `POST /edit-mode`, route name `edit-mode.update`, middleware `auth` + `role(admin|manager|teacher)`, JSON body `{ enabled: boolean, courseId: positive int, from: 'show' | 'learn' | 'builder' }`.
  - on: flag `{ userId }` set, redirect `courses.builder`.
  - off: flag forgotten, redirect `{ show: courses.show, learn: courses.learn, builder: courses.learn }[from]`.
  - refused (policy): flash error « Vous ne pouvez pas modifier ce cours. Contactez son responsable. », redirect `courses.show` from builder, else the same page; flag untouched.
  - student: 403 (role middleware); visitor: 302 `/login`; invalid body: not 2xx; unknown course: 404; no CSRF token: rejected.
- `AuthController.logout` calls `session.forget(EDIT_MODE_KEY)` after `auth.use('web').logout()`.
