## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Japa 4 (`@japa/runner`, api-client with session/shield/inertia plugins, browser-client) |

| **Full suite command** | `node ace test unit && node ace test functional` (+ `node ace test browser` in CI) |
| **Estimated runtime** | ~90 seconds (functional on SQLite) |

---

## Sampling Rate

- **After every task commit:** the touched spec file on SQLite + `bun run typecheck`; `bun run lint` (jsx-a11y) for frontend tasks
- **After every plan wave:** `node ace test unit && node ace test functional`, `bun run lint`, `bun run check:debt`
- **Before `/gsd:verify-work`:** full suite green; CI matrix + e2e (`header.spec.ts`, `accessibility.spec.ts`, and the existing builder/navigation/user_management specs, which render the new header) green
- **Max feedback latency:** 120 seconds
