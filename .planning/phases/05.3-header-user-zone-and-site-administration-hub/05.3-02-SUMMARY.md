## Handoff notes for 05.3-04

- **Required:** wrap the header in exactly one `<TooltipProvider delayDuration={300}>`. A Radix `Tooltip` throws when it has no provider.
- `HeaderSearch` calls `onOpenChange(false)` once on mount, then again on every change of `open`.
- After Escape the typed query is kept, so it shows again when the search is reopened. Focus goes back to the magnifier.
- The magnifier only exists while the search is closed, so its `aria-expanded` is always `false` (as the spec says).
- Blur closes the field only when the trimmed value is empty.
- Any Inertia `navigate` closes the bar search.
- `EditModeSwitch` renders nothing unless `courseEditing.canEdit === true` and the component is `courses/show|learn|builder`. It does not flip optimistically; the server redirect brings the new `editMode`.
