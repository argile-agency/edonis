## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Teacher → another teacher's course content | Builder mutations must stay within the authorized course |
| Enrolled student → other courses' content | `?content=` and progress endpoints |
| Any authenticated user → private course outline / progress | AS3 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-43 | Tampering | `reorderModules` (A2) | mitigate | `where('course_id', course.id)` in a transaction; test asserts other course's module untouched. |
| T-02-44 | Tampering | `reorderContents` (A3) | mitigate | `where('module_id', module.id)`; test asserts foreign content untouched. |
| T-02-45 | Information Disclosure | `learn?content=` (A5) | mitigate | `whereHas('module', course_id = course.id)` + `firstOrFail`; test asserts 404. |
