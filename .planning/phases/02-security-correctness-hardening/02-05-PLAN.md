<objective>
Fix the enrolment controller's authorization and input handling.
- `unenroll` and `enrollManual` read `auth.user!.roles.some(...)` on routes where roles are never loaded. That is a TypeError, so **self-unenrolment is impossible today** (A1).
- All four POST actions read raw `request.only(...)`. Missing fields produce `undefined.toLowerCase()` and `for...of undefined` TypeErrors.
- Method, group and method ids are never scoped to the course in the URL (A9).

The plan then ships behaviour change **AS4**, a server-side `course.canEnroll()` check on self and key enrolment, as an isolated commit behind its own human checkpoint.

Purpose: DEBT-04 (policy layer) and DEBT-05 (validators V9-V12) for `enrollments_controller.ts`. Counter atomicity is plan 02-13, so this plan leaves the read-modify-write counter lines exactly as they are.

Output:
- `app/validators/enrollment.ts`
- a policy-routed, validated controller
- A1, A9 and validation tests
- the AS4 commit, then the AS4 confirmation checkpoint
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student → enrolment endpoints | Untrusted body (method id, key, message) |
| Teacher → manual enrolment of other users | Must hold `manage` on the course in the URL |
| Enrolment owner / staff → unenrol | Self or `manage` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-21 | Denial of Service | `unenroll` / `enrollManual` TypeError (A1) | mitigate | Policies use `hasRole` lazy-load; A1 regression test. |
| T-02-22 | Tampering | cross-course `enrollmentMethodId` / `groupId` (A9) | mitigate | All lookups scoped `where('course_id', <url course>)`; tests assert no cross-course rows/counters. |
| T-02-23 | Tampering / DoS | malformed bodies → 500 | mitigate | VineJS validators with bounds (`maxLength(100)` key, `maxLength(2000)` message, `userIds` 1..500). |
| T-02-24 | Elevation of Privilege | self-enrol into draft/closed course (A10) | mitigate | AS4 `CoursePolicy.enroll` check, gated by human checkpoint; revertable commit. |
| T-02-25 | Elevation of Privilege | `courseRole` free text in manual enrol | mitigate | `vine.enum` of the 6 `CourseRole` values. |
</threat_model>
