<objective>
Lay the authorization foundation that every other Phase 2 authorization plan builds on, and that Phase 12 will extend later.

The plan installs Bouncer 3 (pinned; 4.x needs AdonisJS core 7). It defines `CoursePolicy` and `EnrollmentPolicy` with **behaviour-preserving** rules, including the actions that later plans need (`enroll`, `viewGradebook*`). That way later plans only call policy actions. It does not create them. The plan intercepts Bouncer denials in the exception handler so Inertia users see a proper 403 page, adds the shared test factories, and proves the whole chain end-to-end by moving `grades_controller.course` onto the policy.

Purpose: DEBT-04 (resource-ownership authorization lives in `app/policies/`). This plan makes the layer exist and work. Plans 02-04, 02-05 and 02-10 migrate the remaining controllers.

- Bouncer installed and configured
- 2 policies
- the policy registry
- the handler intercept
- `errors/forbidden.tsx`
- `tests/functional/helpers/factories.ts`
- a policy decision-matrix spec
- the grades controller migrated, with Phase 1's 403 test upgraded to assert the new page
</objective>
