<objective>
Ship behaviour change **AS2** as an isolated, confirmable, revertable unit. Today the course gradebook (`grades.course`) admits only the course owner and enrolled users. **Admins and co-instructors who hold an `edit` permission get 403.** Every other course surface grants both of them. The rule was probably an oversight.

This plan does not touch `grades_controller.ts`. Plan 02-01 already made it ask `viewGradebook` and `viewGradebookAsInstructor`, so the change is policy-only.

Purpose: DEBT-04 policy consolidation, AS2 (RESEARCH § Assumptions Log). This is a locked user decision: each behaviour change ships behind its own `checkpoint:human-verify`.

Output: one `feat(grades):` commit (policy + tests), then the AS2 confirmation checkpoint.
</objective>
