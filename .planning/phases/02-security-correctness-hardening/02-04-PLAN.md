| action | signature |
|---|---|

Named export from the same file: `scopeVisibleCourses(query, user)`, which applies today's role-based listing filter and returns the builder.

Controller usage:
- `async action({ bouncer, ... }: HttpContext)`
- `await bouncer.with('CoursePolicy').authorize('edit', course)` throws → `errors/forbidden` (403) via the handler
- `await bouncer.with('CoursePolicy').allows('edit', course)` → boolean

Test helpers (`tests/functional/helpers/factories.ts`): `uniqueSuffix`, `ensureRole`, `createUser({ roles })`, `createCourse(instructor, overrides)`, `grantPermission(course, user, level)`, `enrollUser(course, user)`, `createEnrollmentMethod(course, overrides)`, `createGroup(course, overrides)`.

- `courses.edit/update/destroy/publish/archive/permissions.*`: `role: admin|manager|teacher`
- `/admin/courses/*` and `/admin/courses/approval-queue|:id/approve|:id/reject`: `role: admin`
- `role_middleware` returns a JSON 403 before the controller runs, so use a teacher (not a student) to exercise POLICY denials on those routes.
